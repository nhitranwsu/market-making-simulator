# Avellaneda-Stoikov Market-Making Simulator

Streamlit app simulating an inventory-aware market maker (Avellaneda and Stoikov, 2008): reservation price, optimal spread, fills, inventory and P&L.

Author: Nhi Q Tran. Copyright (c) 2026 Nhi Q Tran. All rights reserved. See LICENSE.

Run locally: `pip install -r requirements.txt && streamlit run app.py`
